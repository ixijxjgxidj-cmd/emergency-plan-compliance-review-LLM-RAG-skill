# 预案类型 — 法规基线矩阵

**用法与效力声明**

本文件是**检索线索**，不是可直接引用的法律依据。

- Agent0 用它生成"适用法规基线清单"和"必备要素清单"。
- Agent1 用它比对"基线要求的法规本地是否有对应文件"，缺失者记入 `baseline_missing`（只记事实）。
- Agent5A/5B 在**引用**某法规做审查结论前，该法规必须已经通过 `./laws/` 下的用户提供文件进入知识库；本文件中的名称、文号、年份一律以入库文本为准，若不一致以入库的官方文本为准并在 `law_metadata.json` 的 `notes` 中记录差异。
- 本文件不含条文原文，任何条文摘录只能来自知识库。

---

## 一、预案类型判定维度

Agent0 必须逐项判定并写入 `plan_profile.json`：

| 维度 | 取值 |
|------|------|
| `plan_class` | 总体应急预案 / 专项应急预案 / 部门应急预案 / 单位综合应急预案 / 单位专项应急预案 / 现场处置方案 / 重大活动保障方案 / 基层组织预案 / 其他 |
| `event_category` | 自然灾害 / 事故灾难 / 公共卫生事件 / 社会安全事件 / 综合（多类别） |
| `event_subtype` | 如 危险化学品事故、矿山事故、火灾、道路交通、水旱灾害、地震、气象灾害、地质灾害、环境污染、特种设备、传染病疫情、食品安全、群体性事件…… |
| `authority_level` | 国家 / 省 / 市 / 县（区）/ 乡镇（街道）/ 村（居）/ 企业事业单位 |
| `issuer_type` | 人民政府 / 政府部门 / 企业 / 事业单位 / 社会组织 |
| `region` | 具体行政区划（用于确定应适用的地方性法规、地方政府规章、地方预案管理办法） |
| `plan_version` | 版本号 / 修订年份 / 发布日期 |

判定依据：预案封面、发布通知、总则（编制目的/依据/适用范围）、章节结构、发布主体。
若无法唯一判定，列出候选并询问用户，**不得默认按某一类型处理**。

## 二、通用基线（所有预案类型均须检索）

无论何种预案，以下层级的规范都应纳入基线清单（具体名称与最新版本以入库文本为准）：

1. **突发事件应对的基础性法律**：突发事件应对领域的全国性法律。
2. **应急预案管理的国家层面制度文件**：国务院办公厅关于突发事件应急预案管理的办法/规定。
3. **应急预案编制的国家标准 / 行业标准**：预案编制导则类标准（生产经营单位、行政机关等分别有对应标准）。
4. **本地区的地方性法规与地方预案管理办法**：省级突发事件应对条例、省/市突发事件应急预案管理办法、省/市预警信息发布管理办法。
5. **上级同类预案**：上一级人民政府或主管部门的总体预案与同专项预案（用于审查衔接性）。
6. **政府信息公开、个人信息保护等横向制度**（仅当预案涉及信息发布、个人信息处理时纳入）。

## 三、按事件类别的专项基线线索

> 下列仅给出"应当去检索的法规主题"，不写具体条文。名称与年份以入库的官方文本为准。

### 事故灾难类

| 子类 | 应检索的法规主题 |
|------|------------------|
| 通用（生产安全） | 安全生产法；生产安全事故应急条例；生产安全事故应急预案管理办法；生产安全事故报告和调查处理条例；生产安全事故应急演练相关规范 |
| 危险化学品 | 危险化学品安全管理条例；危险化学品重大危险源相关标准与监督管理规定；危险化学品建设项目/经营许可相关规章；危险化学品单位应急救援器材配备标准 |
| 矿山 | 矿山安全法；煤矿/非煤矿山安全规程与相关部门规章 |
| 火灾 | 消防法；消防救援与火灾事故应急相关规章、消防技术标准 |
| 道路/水上/铁路/民航交通 | 道路交通安全法；水上交通安全法；铁路法；民用航空法及相应事故应急处置规定 |
| 特种设备 | 特种设备安全法及事故报告与调查处理相关规定 |
| 建筑施工 | 建筑法；建设工程安全生产管理条例 |
| 环境污染（突发环境事件） | 环境保护法；突发环境事件应急管理相关办法与应急预案管理办法；水/大气/土壤污染防治法中的应急条款 |
| 电力/燃气/供水等城市生命线 | 电力法、城镇燃气管理条例、城市供水条例等及对应应急规定 |
| 核与辐射 | 核安全法、放射性污染防治法及核事故应急相关条例 |

### 自然灾害类

| 子类 | 应检索的法规主题 |
|------|------------------|
| 水旱灾害 | 防洪法；抗旱条例；防汛抗旱应急相关规定 |
| 地震 | 防震减灾法；破坏性地震应急条例 |
| 气象灾害 | 气象法；气象灾害防御条例；预警信息发布管理规定 |
| 地质灾害 | 地质灾害防治条例 |
| 森林草原火灾 | 森林法；草原法；森林防火条例；草原防火条例 |

### 公共卫生事件类

传染病防治法；突发公共卫生事件应急条例；国境卫生检疫法；食品安全法及其实施条例；疫苗管理法、药品管理法（视预案内容）；动物防疫法（人畜共患）。

### 社会安全事件类

人民警察法；治安管理处罚法；反恐怖主义法；集会游行示威法；网络安全法（涉网络事件）；信访、群体性事件处置相关规范性文件。

### 重大活动保障

大型群众性活动安全管理条例；活动举办地的地方性规定；消防、交通、卫生、食品等专项保障要求。

## 四、必备要素清单（按预案类型）

Agent5A 的"要素缺失"类规则据此生成；具体法定要求以知识库中的编制导则/管理办法条文为准。

### 政府总体应急预案

总则（编制目的、编制依据、适用范围、工作原则、预案体系）；风险分析与承受能力；组织指挥体系与职责；运行机制（风险防控、监测预警、应急处置、恢复重建）；应急保障；预案管理（编制、审批、发布、备案、演练、评估、修订、宣教培训）；附则与附件。

### 政府专项 / 部门应急预案

总则；事件分级标准；组织体系与部门职责分工；监测与预警（含预警级别、发布主体与程序）；信息报告（时限、路径、内容）；应急响应（分级响应、启动与终止条件及权限）；处置措施；信息发布与舆情；后期处置；应急保障；监督管理（演练、培训、奖惩）；附件（指挥架构图、流程图、通信录、物资清单）。

### 单位综合应急预案

总则；单位风险与应急能力评估；应急组织机构与职责；风险防控与应急准备；预警与信息报告；应急响应（分级、启动、处置程序、扩大响应、响应终止）；后期处置；应急保障（队伍、物资装备、通信、资金）；培训与演练；预案管理（评审、备案、修订、公布）；附件（专项预案与现场处置方案目录、通信录、装备清单、协议、图表）。

### 单位专项应急预案

适用的事故风险类型与危险性分析；应急组织机构与职责；处置程序；处置措施；应急物资与装备；与综合预案的衔接。

### 现场处置方案

事故风险描述；应急工作职责；应急处置（应急处置程序、处置措施、报告要求）；注意事项。要求简明、可操作、岗位责任到人。

### 重大活动保障方案

活动概况与风险评估；指挥体系与责任分工；各专项保障（安保、消防、交通、医疗卫生、食品、气象、通信、电力）；预警与响应；疏散与救援；信息发布；演练与培训；附件。
